# Linear Algebra in C++

This is a learning project where I implement concepts from _Introduction to Linear Algebra_ by Gilbert Strang.

The goal is to improve my C++ skills while building a deeper understanding of linear algebra through code.

This project is not intended to be a high-performance linear algebra library. Instead, it is a personal study project focused on learning, experimentation, and gradual improvement.

## Goals

- Implement the main concepts from the book
- Practice C++ fundamentals
- Understand linear algebra by building things from scratch
- Improve the code over time as I learn more
